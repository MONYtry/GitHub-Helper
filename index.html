GitHub - Cheatsheet

Ich habe diese Website gebaut um Überblick zu behalten.
Aktuell lerne ich mit GitHub besser umzugehen daher kam die Idee.

Was ist GitHub?

GitHub ist die verbessere Nutzung von Git (Eine Versions-Kontrolle)

Pull-Requests

Eine Pull-Request ist ziemlich simpel. Sie wird erstellt, wenn man Änderungen aus einem Branch in einen anderen übernehmen möchte.

Commit

Ein Commit speichert Änderungen an einem Projekt. So kann man später nachvollziehen, was geändert wurde.

git commit -m "Nachricht"

Merge

Mit einem Merge werden die Änderungen aus einem Branch in einen anderen Branch übernommen.

git merge (name)

Branch

Ein Branch ist wie ein Arbeitsplatz. Für große Projekte essenziel!
Es hilft Übersicht zu behalten und mit anderen zu kooperieren.

git checkout -b (name)
